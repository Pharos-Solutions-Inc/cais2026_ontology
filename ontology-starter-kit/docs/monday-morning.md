# Monday morning

One hour. One domain. Version 1.0 your team can test by lunch.

| Time | Do this |
|---|---|
| 9:00 | Pick one domain: the one where a wrong AI answer costs you the most. |
| 9:10 | Run the interview. Claude Code: `/ontology-interview`. Codex: "Run the ontology interview." Claude, ChatGPT, or Copilot: paste `prompts/03-interview.md`. |
| 9:40 | Ask one real question twice, with and without the file. Use `prompts/04-test-it.md`. |
| 9:50 | Send the file and the diagram to each rule owner. Ask one question: "Is this rule right?" |
| 10:00 | Save it as version 1.0.0. Load it into your team's AI project. |

## The target for version 1.0

- **1 domain.** Not the whole company.
- **10 terms.** The words an outsider gets wrong.
- **3 rules.** The judgment calls your best people make without thinking. Each one has an ID and an owner.

## After Monday

When an answer is wrong, find the missing term, code meaning, or rule. Add it. Log the change. That is the practice.
