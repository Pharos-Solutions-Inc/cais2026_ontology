# Prompt 4: Test it

The proof is the difference. Ask the same real question twice.

1. Create two projects, or two chats, in the same tool. Load the same data files into both.
2. Add your ontology file to the second one only, with this instruction:

```
Read ontology.yaml before you answer any question about our business. Use its terms. Apply every rule that fits and cite the rule ID, for example [Rule-02].
```

3. Ask both the same question. Pick one where your best people would say "it depends."
4. Compare. Look for three things: the right terms, the right rules, and rule IDs you can trace.

When the answer with the file is still wrong, the file is missing a term, a code meaning, or a rule. Add it. That is how the ontology grows.

## Español

```
Lee ontology.yaml antes de contestar cualquier pregunta sobre nuestro negocio. Usa sus términos. Aplica cada regla que corresponda y cita el ID de la regla, por ejemplo [Rule-02].
```
