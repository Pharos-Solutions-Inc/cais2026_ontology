Send this in the same chat, right after Prompt 1, or paste your ontology file above it.

## English

```
Turn the ontology above into a Mermaid flowchart that a business person can review in 30 seconds.
- One box per entity. Label every arrow with its relationship verb.
- Put each rule ID (Rule-01, Rule-02...) inside the box of the entity it applies to.
- Group the boxes by business area.
- Color the boxes that carry a rule gold and the rest white.
Return the Mermaid code only.
```

```
Convierte la ontología de arriba en un diagrama de flujo Mermaid que una persona de negocio pueda revisar en 30 segundos.
- Una caja por entidad. Rotula cada flecha con el verbo de la relación.
- Pon el ID de cada regla (Rule-01, Rule-02...) dentro de la caja de la entidad a la que aplica.
- Agrupa las cajas por área del negocio.
- Pinta de dorado las cajas que llevan una regla y de blanco las demás.
Devuelve solo el código Mermaid.
```
